Web Service là một hệ thống cho phép các ứng dụng khác nhau giao tiếp và trao đổi dữ liệu với nhau thông qua mạng Internet hoặc mạng nội bộ bằng các giao thức chuẩn như HTTP.

Web Service giúp các hệ thống viết bằng ngôn ngữ khác nhau (Java, PHP, Python, .NET, …) vẫn có thể trao đổi dữ liệu với nhau.
| Tiêu chí             | SOAP                    | REST           |
| -------------------- | ----------------------- | -------------- |
| Kiểu hoạt động       | Giao thức               | Kiến trúc      |
| Giao thức truyền tải | HTTP, SMTP              | Chủ yếu HTTP   |
| Định dạng dữ liệu    | XML                     | JSON, XML      |
| Tốc độ xử lý         | Chậm hơn                | Nhanh hơn      |
| Độ phức tạp          | Cao                     | Thấp           |
| Trạng thái           | Stateful hoặc Stateless | Stateless      |
| Độ bảo mật           | Cao với WS-Security     | Dùng HTTPS/JWT |
| Khả năng mở rộng     | Khó hơn                 | Linh hoạt hơn  |
| Mức độ phổ biến      | Ít hơn hiện nay         | Rất phổ biến   |
