Web Service là một hệ thống cho phép các ứng dụng khác nhau giao tiếp và trao đổi dữ liệu với nhau thông qua mạng Internet hoặc mạng nội bộ bằng các giao thức chuẩn như HTTP.

Web Service giúp các hệ thống viết bằng ngôn ngữ khác nhau (Java, PHP, Python, .NET, …) vẫn có thể trao đổi dữ liệu với nhau.
| Tiêu chí                | SOAP                           | REST                |
| ----------------------- | ------------------------------ | ------------------- |
| Giao thức truyền tải    | Chủ yếu dùng HTTP, SMTP        | Chủ yếu dùng HTTP   |
| Định dạng dữ liệu chính | XML                            | JSON, XML           |
| Trạng thái              | Có thể stateful hoặc stateless | Stateless           |
| Tính dễ dàng triển khai | Phức tạp hơn                   | Đơn giản hơn        |
| Tốc độ xử lý            | Chậm hơn do XML nặng           | Nhanh hơn           |
| Độ bảo mật              | Bảo mật cao (WS-Security)      | Phụ thuộc HTTPS/JWT |
| Khả năng mở rộng        | Khó mở rộng hơn                | Dễ mở rộng          |
